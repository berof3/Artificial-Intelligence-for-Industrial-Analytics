# Artificial Intelligence for Industrial Analytics

This repository contains a comprehensive suite of projects focused on the application of Deep Learning and mathematical optimization techniques within industrial contexts. The projects cover the full lifecycle of neural network development, from fundamental optimization theory to the implementation of complex architectures for classification and regression tasks.

### Project Modules

### 1. Artificial Neural Networks for Classification
*   **Objective**: Developing and training a Multi-Layer Perceptron (MLP) to solve complex categorical classification problems.
*   **Key Tasks**: Data preprocessing, feature scaling, architectural design (hidden layers, neurons, activation functions), and performance evaluation using confusion matrices and accuracy metrics.
*   **Tools**: Python, TensorFlow/Keras, Scikit-learn.

### 2. Artificial Neural Networks for Regression
*   **Objective**: Implementing Deep Learning models to predict continuous industrial variables (e.g., machinery output, temperature, or yield).
*   **Key Tasks**: Handling skewed numerical data, optimizing Mean Squared Error (MSE), and utilizing dropout layers to prevent overfitting.
*   **Tools**: Python, Pandas, NumPy, Matplotlib.

### 3. Gradient Descent Based Optimization
*   **Objective**: Exploration of the mathematical foundations of model training.
*   **Key Tasks**: Implementing and visualizing various optimization algorithms (Stochastic Gradient Descent, Adam, etc.) to understand convergence behaviors and local minima avoidance in high-dimensional loss surfaces.

These projects demonstrate the ability to:
